# Anexo - Patrones de Diseño

Los patrones de diseño son soluciones de arquitectura reutilizables a problemas recurrentes en el desarrollo de software orientado a objetos. No son código listo para copiar y pegar, sino modelos que indican cómo organizar clases, responsabilidades y colaboraciones para lograr sistemas más flexibles, mantenibles y fáciles de extender. Al aplicar patrones de forma consciente, se reduce el acoplamiento innecesario, se mejora la cohesión de las clases y se facilita la evolución del proyecto sin romper funcionalidades existentes.
